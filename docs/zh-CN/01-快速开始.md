# 01 · 快速开始

> [English](../en/01-quick-start.md) | [简体中文](01-快速开始.md)

在任意 Docker 环境部署 DeepSeek Harness（DSH）。

## 1. 前置要求

- 支持 `docker compose` v2 的 Docker Engine ≥ 20.10。
- 能够拉取 `node:24-slim`（国内网络建议配置 registry 镜像加速，见 [05](05-平台差异.md)）。
- 一个 DeepSeek API Key（或其他兼容模型 API）。

## 2. 目录结构

```
dsh-docker-server/
├── docker-compose.yml   # 部署配置
├── Dockerfile           # 基础镜像（可自行构建或直接用 ghcr.io 镜像）
├── scripts/             # 运行时代码（entrypoint / rescue CLI / 共享库 / 探针）
└── .env.example         # 环境变量模板
```

## 3. 安装步骤

### 3.1 拉取仓库并配置

```bash
git clone https://github.com/steven-stack-s/dsh-docker-server.git
cd dsh-docker-server

cp .env.example .env
# 编辑 .env，至少填写：
#   DEEPSEEK_API_KEY=sk-你的密钥
# 其余变量有默认值，可按需调整（端口、数据目录、资源限制等）
```

> `.env` 已被 `.gitignore` 忽略，密钥不会进入 git。

### 3.2 启动

```bash
docker compose up -d
```

首次启动时 `scripts/entrypoint.sh` 会从镜像内 seed（`/opt/dsh-seed`）把 dsh+pnpm 复制到挂载卷 `/opt/dsh`，秒级完成、离线、版本固定（compose 健康检查的 `start_period` 为 300s，用来容纳首启复制 seed 与冷启动）。

### 3.3 查看启动日志

```bash
docker logs dsh --tail 15
```

预期输出：

```
[entrypoint] first boot: seeding @deepseek-ai/dsh into mounted volume /opt/dsh ...
[entrypoint]   copying in-image seed (/opt/dsh-seed) to /opt/dsh
[entrypoint] dsh ready: /opt/dsh/bin/dsh
[entrypoint] starting socat forward: 0.0.0.0:3080 -> 127.0.0.1:3081 (max-children=64)
[entrypoint] starting dsh web (internal 127.0.0.1:3081)
dsh web: http://127.0.0.1:3081/?token=xxxxxxxx   # ← 启动 token，打印在 "dsh web:" 这一行
```

- 不应出现 "opening the default browser"（已加 `--no-open`）。
- 启动瞬间 socat 的 `Connection refused` 属正常（dsh 尚未就绪），dsh 起来后消失。
- 复制 `dsh web:` 行里的 `?token=...` 值——首次访问要用（见第 4 节）。

## 4. 用启动 token 访问

dsh 核心**不需要管理员账号**即可使用。首次启动会签发一个**启动 token**——打印在容器日志（见 §3.3），用于放行首次访问。每次重启 token 都会变化。

- **首次访问**：打开 `http://<主机IP>:3080/?token=<日志里的token>`
- **之后访问**（同一运行实例）：无需再带 token，直接打开 `http://<主机IP>:3080`

> 若从局域网 IP 或域名访问，且该地址不在 dsh 的自动放行名单里，请先在 `.env` 的 `DSH_TRUSTED_HOSTS` 中加上它再启动——否则页面能开但每个 `/api` 请求都会返回 403（见 `.env` 注释；dsh 0.1.2 只信任 loopback 或白名单 Host）。**例外**：装了认证插件 dsh-remote 时不需要白名单——登录后它会把已认证请求的 Host 归一为 loopback，访问控制由账号密码接管（实测任意域名/隧道 Host 登录后 `/api` 均 200）。
>
> 想为**远程**访问加用户名密码 + MFA？那就是 [dsh-remote](https://github.com/xgone/dsh-remote) 插件，见 [02](02-认证与远程访问.md)。dsh 本身不需要账号。

## 5. 验证

- 浏览器打开 `http://<主机IP>:3080`（首次用 `http://<主机IP>:3080/?token=<日志里的>`），随后开新会话即可与模型对话。
- 设置 → 模型，确认 API Key 已生效。
- `docker ps` 中 `dsh` 容器状态为 healthy（首次启动从 seed 复制，秒级就绪，starting 时间很短）。

## 6. 停止 / 卸载

```bash
docker compose down          # 停止并移除容器（数据保留在 ./dsh ./programs ./workspace）
docker compose down -v       # ⚠️ 连同匿名卷一起删除（本方案未用命名卷，数据在挂载目录，不受影响）
rm -rf dsh programs workspace # 彻底删除数据
```
